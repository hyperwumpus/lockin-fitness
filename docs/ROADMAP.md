# LOCK//IN roadmap

## V0.1 — Original browser loop (September 21, 2026)
Quests, Full Body A/B, rest timer, preset meal missions, manual protein tally, weight, penalty vault, Content Capture.

## V0.2 — Food workflow (this build)
Dated food diary; calories, protein, carbs, fat; manual entries; Open Food Facts barcode lookup; optional browser camera; old data migration; daily quest reset.

## Next — Native iPhone shell
SwiftUI + SwiftData, Today/Train/Fuel/Stats/Content, migration/export plan, native camera scanning. Work through an actual iPhone build before claiming native features are available.

## Later — Execution and progression
Notifications and alarms within iOS constraints, HealthKit, workout sets/reps/weight history, saved foods and meals, progression engine, character skill tree, configurable consequences and weekly reports.
